# Backend — The Alt-Text Alibi

This folder is organizer-only. Category: Web / OSINT; difficulty: Easy.

## Construction
The distributed participant artifact is in the sibling `10_The_Alt_Text_Alibi_Participants/` directory. The canonical flag is stored in the sibling solution folder. This challenge uses synthetic data only.

## Intended method
Compare alt text across a local gallery page.

## Regeneration and validation
Run `python build.py` from this directory. It rebuilds a copy of the participant artifact(s) in `rebuilt/` using the deterministic source description in `challenge.json`. Compare the rebuilt artifact with the distributed one where applicable.
