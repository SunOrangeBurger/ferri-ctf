# Backend — QR Without the R

This folder is organizer-only. Category: Image / Encoding; difficulty: Medium.

## Construction
The distributed participant artifact is in the sibling `14_QR_Without_The_R_Participants/` directory. The canonical flag is stored in the sibling solution folder. This challenge uses synthetic data only.

## Intended method
Reconstruct text from row-wise QR-like binary grid.

## Regeneration and validation
Run `python build.py` from this directory. It rebuilds a copy of the participant artifact(s) in `rebuilt/` using the deterministic source description in `challenge.json`. Compare the rebuilt artifact with the distributed one where applicable.
