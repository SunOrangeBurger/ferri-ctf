# Backend — Bitwise Breakroom

This folder is organizer-only. Category: Encoding; difficulty: Easy.

## Construction
The distributed participant artifact is in the sibling `04_Bitwise_Breakroom_Participants/` directory. The canonical flag is stored in the sibling solution folder. This challenge uses synthetic data only.

## Intended method
Convert supplied 8-bit binary groups to ASCII.

## Regeneration and validation
Run `python build.py` from this directory. It rebuilds a copy of the participant artifact(s) in `rebuilt/` using the deterministic source description in `challenge.json`. Compare the rebuilt artifact with the distributed one where applicable.
