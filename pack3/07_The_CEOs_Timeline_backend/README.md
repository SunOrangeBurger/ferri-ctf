# Backend — The CEO's Timeline

This folder is organizer-only. Category: Log Analysis; difficulty: Medium.

## Construction
The distributed participant artifact is in the sibling `07_The_CEOs_Timeline_Participants/` directory. The canonical flag is stored in the sibling solution folder. This challenge uses synthetic data only.

## Intended method
Sort event timestamps and extract first letters of event labels.

## Regeneration and validation
Run `python build.py` from this directory. It rebuilds a copy of the participant artifact(s) in `rebuilt/` using the deterministic source description in `challenge.json`. Compare the rebuilt artifact with the distributed one where applicable.
