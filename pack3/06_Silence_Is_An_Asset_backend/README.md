# Backend — Silence Is an Asset

This folder is organizer-only. Category: Audio; difficulty: Medium.

## Construction
The distributed participant artifact is in the sibling `06_Silence_Is_An_Asset_Participants/` directory. The canonical flag is stored in the sibling solution folder. This challenge uses synthetic data only.

## Intended method
Decode Morse from short/long tone durations in a WAV file.

## Regeneration and validation
Run `python build.py` from this directory. It rebuilds a copy of the participant artifact(s) in `rebuilt/` using the deterministic source description in `challenge.json`. Compare the rebuilt artifact with the distributed one where applicable.
