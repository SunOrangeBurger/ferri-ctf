# CaughtRedHanded backend

No static challenge can reliably prove AI use. Generate a per-team case: `python generate_case.py --team TEAM_ID --seed PRIVATE_EVENT_SEED --out private_case.json`. Keep the JSON private; distribute only the case ID, nonce, and matching artifact variant. Require a concise evidence transcript and optionally one oral follow-up. Do not rely on writing style or AI detectors alone.
