# The Git Ghost

**Category:** Source Code  
**Difficulty:** Medium

The fictional company has produced another artifact and a confident explanation that should not be trusted without checking evidence.

## Objective
Recover the flag from the supplied evidence. All data is synthetic; no real accounts or systems are involved.

## Files
- `snapshot_after.py`
- `snapshot_before.py`
- `commit_log.txt`

## Rules
- Flag format: `nexus{...}`.
- Browser and Python 3 are sufficient; standard-library methods are preferred.
- Do not run unknown binaries or upload artifacts to third-party services.
- Keep a short evidence trail; a lucky guess is not a reproducible solution.

## Hint
Check field notes, compare related artifacts, and validate each transformation against the supplied evidence. For image challenges, channel selection and pixel order matter.
